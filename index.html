O QUE NÓS PODEMOS FAZER PARA TORNAR NOSSA ESCOLA AINDA MELHOR?

O cuidado com o patrimônio da escola é responsabilidade
de todos os estudantes e funcionários, os bens duráveis são importantes para o desenvolvimento
dos estudantes e gera um ambiente melhor para todos os envolvidos.

Gostaríamos de pedir uma atenção especial para a nossa quadra de vôlei, que atualmente precisa de reparos para que possamos jogar com segurança. A rede está bastante desgastada e os postes precisam de ajustes para garantir a altura e a tensão corretas, além de o piso precisar de uma revisão nas marcações. Como o esporte é fundamental para o nosso lazer e saúde, contamos com o apoio de vocês para renovar esse espaço. Ficamos à disposição para ajudar no que for preciso!
